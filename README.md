## 📌 Overview

This repository contains an **interactive Power BI dashboard** created using a publicly available *Data Professional Survey* dataset. The dashboard highlights key trends in the data industry, focusing on roles, salaries, skills, and career satisfaction.

This project is part of my **data analytics portfolio** and demonstrates my ability to clean data, build meaningful visuals, and communicate insights effectively using Power BI.

---

## 🛠 Tools Used

* **Power BI Desktop**
* **Power Query** for data cleaning
* **DAX** for calculated measures
* **Excel** (source data format)

---

## 📈 Key Insights

* Distribution of survey takers across countries
* Average salary by job title
* Popular programming languages among data professionals
* Difficulty of breaking into data roles
* Happiness levels with work-life balance and salary
